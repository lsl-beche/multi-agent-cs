# ADR-0001：L2 标准企业级生产系统目标

状态：accepted  
日期：2026-08-30  
决策人：项目负责人  
评审人：后端、安全、运维

## 背景

CSagent 已具备电商、多 Agent 客服、商城、后台和工单能力，但当前仍是同步数据库、内存事件、沙箱支付和模拟物流，尚不能支撑 10 万 DAU、1000 QPS、99.9% 可用性。

## 决策

采用 L2 标准企业级生产系统目标：

- 10 万 DAU、峰值 1000 QPS、2000 WebSocket；
- 月度可用性 99.9%，RPO ≤ 5 分钟，RTO ≤ 30 分钟；
- 阿里云单地域双可用区；
- PIPL + 网络安全等级保护三级自查；
- 模块化单体 + 异步数据库 + PostgreSQL outbox + Redis。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| L1 内部生产 | 快、成本低 | 无法支撑对外业务和高并发 | 不采用 |
| L2 标准企业级 | 规模、可用性、安全、合规可满足 | 改造周期长 | 采用 |
| L3 平台级/SaaS | 多租户、多地域 | 成本、复杂度显著上升 | 暂不采用 |

## 影响

- 主要改造：异步数据库、outbox、真实支付/物流、测试、安全合规；
- 架构选择：保留模块化单体，不拆微服务；
- 阶段目标：P0～P5，约 16～18 周，4～5 人团队；
- 范围限制：第一阶段不做多地域、多租户、App 和自训练模型。

## 验证

- 1000 QPS / 2000 WS 压测；
- 500 并发下单无超卖；
- 权限矩阵、PII 加密、隐私删除、渗透测试；
- 备份恢复、回滚、故障演练。
