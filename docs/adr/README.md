# Architecture Decision Records

## 目的

ADR 用于记录影响架构、安全、数据、部署和质量的重大技术决策，保留决策背景、备选方案、选择理由和后续影响。

## 文件命名

```text
docs/adr/NNNN-short-title.md
```

## 状态

- `proposed`：待评审；
- `accepted`：已接受；
- `superseded`：已被新 ADR 替代；
- `rejected`：已拒绝或不再适用。

## 流程

1. 在 PR 中新增 ADR；
2. 至少 1 名评审人确认；
3. 影响安全、支付、数据库、生产部署的决策至少 2 名评审人确认；
4. 合并后由项目负责人维护状态。
